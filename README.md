## 🌟 Overview
**OptiSim-Lab** is an interactive, browser-based physics-informed machine learning and dynamical systems sandbox. It simulates how optimization algorithms behave like physical particles moving through potential energy wells under viscous damping and thermal Brownian motion[cite: 4].

---

## ✨ Key Features
* **Interactive 2D Physics & ML Sandbox:** Click anywhere on the contour map to launch live multi-agent races[cite: 4].
* **Numerical Solvers:** Implements RK4 + SGLD engines, Finite Differences, and 4th-Order Runge-Kutta methods[cite: 4].
* **Real-time Controls:** Custom sliders for adjusting momentum, viscosity, and thermal noise on the fly.
* **Modern UI:** Styled with Tailwind CSS and responsive design components.

---

## 🛠️ Tech Stack
* **Frontend:** HTML5, Modern JavaScript (ES6+)
* **Styling:** Tailwind CSS CDN
* **Engine:** Custom physics and optimization mathematical models
