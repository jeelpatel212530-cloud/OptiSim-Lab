1. Vanilla SGD Overdamped Limit

Zero inertia (m → 0). Velocity is directly proportional to the negative gradient force:

x_{t+1} = x_t - η∇L(x_t) + σξ_t
2. Heavy-Ball Momentum Polyak (1964)

Introduces exponential velocity memory β to damp high-curvature oscillations:

v_{t+1} = βv_t - η∇L(x_t)
x_{t+1} = x_t + v_{t+1}
3. Adam Optimizer Adaptive Metric

Normalizes each coordinate by the running RMS of its historical gradient √v̂_t:

x_{t+1} = x_t - η · m̂_t / (√v̂_t + ε)
4. RK4 Langevin Ball Underdamped ODE

Full 2nd-order Newtonian mechanics with mass m, drag γ, and thermal bath T:

m ẍ + γ ẋ + ∇U(x) = √(2γT)ξ(t)
